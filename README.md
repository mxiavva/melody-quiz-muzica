# 🎹 Melody — Quiz Muzical

**Melody** este o aplicație web educațională creată pentru a-i ajuta pe muzicanții începători să învețe și să-și testeze cunoștințele de teorie muzicală.

## 🎯 Pentru cine este și cum se joacă
Aplicația este destinată elevilor și tuturor celor care vor să-și dezvolte citirea pe partitură și noțiunile de bază din muzică.
- Apasă pe butonul **START JOC** pentru a începe quizul.
- Citește fiecare întrebare și alege varianta corectă de răspuns dintr-un singur click.
- La final, vei vedea scorul total obținut!

## 🔗 Linkul aplicației
Poți testa aplicația direct online aici:

## 💻 Tehnologii folosite
Proiectul a fost realizat de la zero folosind exclusiv tehnologii web native, fără framework-uri sau biblioteci externe:
- **HTML** — structura paginii și a elementelor interactive.
- **CSS** — stilizarea vizuală, paleta de culori și fonturile.
- **JavaScript** — logica interactivă a quizului, calcularea scorului și verificarea răspunsurilor.

## 🤖 Cum am folosit AI-ul în proiect
AI-ul a fost folosit ca partener de ghidaj în dezvoltare:
- La organizarea structurii aplicației și a pașilor de lucru.
- La identificarea și repararea problemei prin care se putea răspunde de mai multe ori la aceeași întrebare.
- La structurarea acestui fișier de prezentare (`README.md`).
